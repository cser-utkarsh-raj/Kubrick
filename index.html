PRECISION VIDEO EDITING

Make every second earn its place.

A lightweight, local-first video editor that can automatically tighten spoken footage, while still giving you a simple timeline for cuts, trims, filters, layers and final rendering.

THE ENGINE

Small enough to run locally.
Serious enough to edit.

Kubrick does not try to replace a heavyweight NLE. FFmpeg handles media work; the Kubrick engine handles decisions, timeline state and composition. The UI stays focused instead of becoming a 300-button workstation.

01 / AUTOMATE
◒

Automatic cleanup

Silence, speech and visual evidence become explainable edit decisions instead of opaque AI guesses.

02 / EDIT
⌁

Core editor operations

Cut, trim, merge, speed, volume, filters, audio layers, text, images and shapes are represented in one project.

03 / RENDER
◇

One synchronized output

The project is rendered locally through a single FFmpeg graph so audio and video decisions stay together.

WORKFLOW

Import. Automate.
Adjust. Render.

You can use Kubrick from the desktop GUI or from the command line. The GUI is the intended everyday experience; CLI remains useful for automation and batch workflows.

01

Import

Choose a video and Kubrick probes it locally. No upload is required.

02

Auto Edit

Pick clean, gentle, tight, punchy or mono-voice and build an editable automatic project.

03

Adjust

Inspect clips, cut a range, add filters, text, images or shapes, then save a .kubrick.json project.

04

Render

Render the project to MP4 locally. The browser site never processes your footage.

REQUIREMENTS

Lightweight by design.

Kubrick itself is modest. Video encoding is the part that can become CPU-heavy, especially with high-resolution footage or long exports.

BASELINE TO RUN KUBRICK

Minimum system

OSWindows 10/11 · modern Linux · macOS
CPU64-bit, 2 cores
RAM4 GB
Storage~1 GB app/dependencies + free media workspace
GPUNot required
MediaFFmpeg + FFprobe

This is the practical floor for the current development build. 4K, long projects and speech AI need more headroom.

TARGET FOR A COMFORTABLE WORKFLOW

Recommended system

OSWindows 10/11 · modern Linux · macOS
CPU4+ modern cores
RAM8–16 GB
StorageSSD with ample free working space
GPUOptional
Media1080p H.264/H.265 as a sensible baseline
Speech AIExtra CPU/RAM recommended

Rendering can still be CPU-heavy. Lightweight application ≠ lightweight video encoding.
